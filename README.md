# YTKACE source

Unofficial AltStore-format source for [YTKACE](https://github.com/itzzace/ytkace).
A GitHub Action checks the upstream releases every 6 hours and updates the JSON.
IPAs download straight from itzzace's GitHub releases; nothing is re-hosted.

Add one of these in Feather, SideStore or AltStore Classic (Sources → +):

| Build | Source URL |
| --- | --- |
| iOS 17 and newer | `https://jimkaram2.github.io/ytkace-source/ytkace.json` |
| iOS 16 | `https://jimkaram2.github.io/ytkace-source/ytkace-ios16.json` |

Not affiliated with YTKACE or YouTube.
